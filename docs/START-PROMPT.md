# Стартов промпт за новата сесия (продължение на кода)

Копирай текста между линиите в нова облачна сесия на Claude Code в хранилището `vankata54/siracusa-sofia`.

---

Здравей! Продължаваме проекта Siracusa Bar & Grill от клон `build/v1`.

1. `git fetch origin build/v1 && git checkout build/v1`.
2. Прочети `CLAUDE.md`, после `docs/STATUS.md` (докъде сме), `docs/BUILD-PLAN.md`, `docs/AGENTS.md`, `docs/CODE-GUIDE.md`, `docs/PAGE-BRIEF.md`, `docs/DECISIONS.md`, `docs/OPEN-QUESTIONS.md`, `docs/BUILD-TODO.md`.
3. `npm install`, `node scripts/make-env.mjs`, `npm test`, `npm run build` — провери, че основата работи.
4. Продължи от раздел „Започнато, недовършено“ в `docs/STATUS.md`, после „Следва“: довърши етап B, проверка на кода, етап C (админ панел), етап D, етап E (на живо).
5. Работи с агенти: един агент на задача, 2-3 независими проверяващи, поправки до ГОТОВО; партиди по 4-5 агента. Агентите не комитват; ти комитваш.
6. Комитвай и push-вай в `build/v1` след всяка завършена част. Казвай ми кратко на български какво е готово и ми давай линк, за да го пробвам.
7. Когато админ панелът е готов, дай ми адреса, потребителя и паролата (паролите не са в git).

Не измисляй факти: каквото липсва, маркирай `[ЛИПСВА: ...]` и го добави в `docs/OPEN-QUESTIONS.md`.
