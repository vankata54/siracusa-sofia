# Задачи за шефа (общи части)
- `setKitchenBusy()` да се вика от runtime-а по настройката от ядрото (кухнята/админът) — сега времето винаги е 35 мин.
- Ядрото да проверява избрания час за вземане.
- 404: текст „Тази категория/ястие я няма в менюто“ за адреси под `/menu/...` + списък с категориите (`catsHTML(null)` от `_cat.ts`).
- `npm run build`/`test:e2e` да могат да пишат в отделна папка (`DIST_DIR`) за паралелна работа.
- `@astrojs/check` за проверка на типовете в `.astro`.
- Количката да слага `fresh: true` в `sc-order`; ratings.submit — един код на поръчка; API за промяна на поръчка „за утре“; Web Push; съгласие за рожден ден без профил; часове на всеки статус в поръчката.
- Офис (ядро): задача на сървъра за крайния час (автоматично изпращане без отворена страница); организатор, дата и телефон в поръчката; проверка на крайния час при join; отказ при второ изпращане; методи update/leave; името на офиса по желание.
- Събития: api.subscribe да пази темите; api.events да връща дата YYYY-MM-DD; датата в HTML/JSON-LD е от билда → нов билд поне веднъж седмично (cron).
