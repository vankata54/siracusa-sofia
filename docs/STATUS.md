## Как се стартира

```
npm install
node scripts/make-env.mjs   # прави .env със случайни пароли, ако липсва (не е в git)
npm test
npm run build && npm run serve   # http://localhost:8787
npm run build:demo               # статично демо в dist/
```

`npm run test:e2e` сам прави build и пуска сървъра на порт 8788; засега строи в `dist/` (презаписва го). Акаунти на персонала: `admin`, `owner`, `manager`, `waiter`, `kitchen`, `driver`; паролите са само в `.env`.

## Уроци

- Агентите пишат в общото работно дърво: всеки ползва свой порт и свои папки за build (`dist-<име>*`, в `.gitignore`), никога `pkill` по общ шаблон.
- Шефът комитва; агентите не комитват.
- Две сесии по едни и същи файлове правят паралелни клонове, които не могат да се слеят: една сесия работи по `build/v1`.
- Лимитите прекъсват агентите: след нулиране се продължава същият агент (SendMessage), не нов.
